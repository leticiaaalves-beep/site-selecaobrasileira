Sobre o projeto:
Este projeto consiste em um site desenvolvido para apresentar informações sobre a Seleção Brasileira de Futebol e seus principais jogadores.
A proposta foi criar uma página visual, organizada e interativa, reunindo os jogadores da Seleção Brasileira em cards com suas respectivas posições em campo.

Objetivo:
O objetivo do projeto é desenvolver uma página web utilizando conceitos de HTML e CSS, praticando a criação de layouts, organização de conteúdo, imagens e estilização de elementos.

Tecnologias utilizadas:
HTML — estruturação da página
CSS — estilização, cores, posicionamento e layout
